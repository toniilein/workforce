Every card you see is a `.md` file in the `tasks/` folder of the repo.

Click a card and GitHub's editor opens on that file — change `status:` to `doing` or `done`, commit,
and the board follows. Agents do exactly the same thing with git.

See `tasks/README.md` for the format.
