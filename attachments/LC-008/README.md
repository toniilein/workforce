# Avatars

Drop a square image here and the board uses it instead of the person's initials.

| Person | File to add |
| --- | --- |
| Toni | `toni.png` |
| Adi | `adi.png` |
| Pookachu Bot | `pookachu.png` |

Square images work best (they are cropped to a circle) — 128×128 or 256×256 is plenty.
`.jpg` works too; if you use a different name or extension, update the `img:` path in
`docs/app.js` to match.

If a file is missing the board simply shows the initials, so nothing breaks while a picture
is still to be added.
