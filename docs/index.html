Connect GitHub

The board saves changes by committing to your repo, which needs a token. It is stored only in this browser and sent only to github.com.

A token is already saved here. Paste a new one below to replace it.

  1. Open your tokens (or make a new one)
  2. Repository access → Only select repositories → workforce
  3. Repository permissions → Contents → Read and write
  4. Save on GitHub, then paste the token here

Tip: let your browser or password manager save this. It then fills in automatically on your other devices, so you only enter it once.
